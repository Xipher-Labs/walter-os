# Walter-OS bootstrap egress allowlist — bundled example.
#
# Walter-OS ships with a DEFAULT-DENY network gate (spec
# docs/specs/network-egress-allowlist.md, OSS Trust epic #122 A-2).
# After install, your `~/.config/walter-os/egress-allowlist.txt` is
# empty, and every outbound network call from the agent is blocked.
#
# This file is the recommended starting set: GitHub, the common package
# registries, the LLM APIs Walter-OS officially supports, the
# Walter-OS-managed services under your domain, and system NTP.
#
# Import via:
#   walter-os egress import \
#     "${WALTER_OS_HOME}/contexts/_examples/egress-allowlist.example.txt"
#
# The import command expands `${WALTER_DOMAIN}` and any other env vars at
# import time. If WALTER_DOMAIN is unset, the two `*.${WALTER_DOMAIN}`
# lines are SKIPPED with a WARN — the rest is still imported.
#
# After import, edit the file directly (the loader re-reads it on every
# request) or use `walter-os egress {add,remove,list}` for one-off
# changes. See `docs/operational/network-egress.md` for the full guide.
