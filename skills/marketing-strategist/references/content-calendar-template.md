# 12-Week Rolling Content Calendar Template

## How to use this template

- Fill in one row per piece of content.
- "Theme" aligns with a monthly pillar (3 themes per quarter = 1 theme per month).
- "Target keyword" maps to the SEO keyword list from the marketing-strategist SEO audit.
- "Distribution channels" lists where this piece will be published and amplified.
- "Owner" is the person or agent responsible for producing the draft.
- "Status" tracks: Idea → Outline → Draft → Review → Scheduled → Published.

## Content type definitions

| Type | Word count / length | Primary goal |
|---|---|---|
| Blog post | 800-1,500 words | SEO + awareness |
| Deep-dive guide | 2,500-5,000 words | SEO + authority |
| Tutorial / how-to | 1,000-2,000 words | SEO + activation |
| Case study | 800-1,200 words | Sales enablement |
| Comparison page | 1,000-1,500 words | Transactional SEO |
| LinkedIn post | 150-300 words | Reach + engagement |
| X thread | 5-10 tweets | Reach + virality |
| Newsletter issue | 400-800 words | Retention + referral |
| Tool / template | Variable | Lead generation |
| Interview | 1,500-2,500 words | Authority + backlinks |

## Quarterly pillar examples

Adapt these to your product area:

- **Pillar 1 — Pain + Problem awareness**: content about the pain your product
  solves; no product mention required.
- **Pillar 2 — Solution education**: how-to content, tutorials, comparisons.
  Mentions product as one path among several.
- **Pillar 3 — Product as hero**: case studies, feature spotlights, success
  stories. Direct product association.
