# Verifying release artifacts

Each Walter-OS release is signed with [cosign](https://github.com/sigstore/cosign)
using keyless OIDC signing (no long-lived private key). The signing identity is
tied to the GitHub Actions OIDC token and is auditable via the
[Rekor](https://github.com/sigstore/rekor) transparency log.

Three artifacts are attached to every release:
- `walter-os-<version>-sbom.json` — CycloneDX SBOM generated by syft
- `walter-os-<version>-checksums.txt` — SHA-256 checksums of release assets
- `walter-os-<version>-cosign.bundle` — cosign transparency log bundle

## Verification steps

```bash
# Download the release assets
gh release download <version> --pattern "walter-os-<version>-*"

# Verify the checksum file signature
cosign verify-blob \
  --bundle walter-os-<version>-cosign.bundle \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity-regexp 'https://github.com/xipher-labs/walter-os/.github/workflows/release-security.yml.*' \
  walter-os-<version>-checksums.txt

# Verify file integrity
sha256sum --check walter-os-<version>-checksums.txt

# Verify the SBOM is listed in checksums
sha256sum --check walter-os-<version>-checksums.txt
```

Replace `<version>` with the target release tag (e.g., `v0.2.0`).

## Note on org/repo slug

The `--certificate-identity-regexp` above uses `xipher-labs/walter-os`.
Older bundles signed before the public org migration remain verifiable with
the identity regexp printed in their release notes.

## Installing cosign

```bash
# macOS
brew install cosign

# Linux (via Go)
go install github.com/sigstore/cosign/v2/cmd/cosign@latest

# Or use the sigstore/cosign-installer GitHub Action in CI
```
