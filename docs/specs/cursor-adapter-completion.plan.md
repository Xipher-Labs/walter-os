## Task 2: Write the Cursor MDC generation function in install.sh [AC-1, AC-2]

- File: `install.sh` (modify)
- Change: Add a `generate_cursor_adapter()` function that:
  1. Creates `~/.cursor/rules/` directory if it does not exist.
  2. Generates `~/.cursor/rules/walter-os.mdc` by extracting the core
     discipline sections from the installed AGENTS.md (rigor levels, branch
     flow, TDD gate, review loop, commit hygiene, PR title convention).
  3. Prepends MDC frontmatter:
     ```
     ---
     description: Walter-OS agent discipline contract
     globs: "**/*"
     ---
     ```
  4. Prepends the required header comment.
  5. Records the AGENTS.md content hash in a comment at the bottom of the
     generated file for staleness detection.
  Wire the function into the main install flow: call it if `~/.cursor/` exists
  (Cursor is detected) OR if `--cursor` flag is passed. Skip with INFO log
  `"Cursor not detected; skipping cursor adapter. Use --cursor to force."` if
  neither condition is true.
- Verify: `bats tests/install/cursor-adapter.bats` passes all four tests (GREEN).

## Task 3: Add `doctor --cursor` subcommand [AC-3]

- File: `bin/walter-os` (modify)
- Change: In `cmd_doctor()`, handle `--cursor` flag:
  - If `~/.cursor/rules/walter-os.mdc` does not exist: print MISSING with
    instructions.
  - If it exists: recompute the AGENTS.md hash and compare with the recorded
    hash in the file. If they match: PASS. If they differ: STALE, print
    `"Run install.sh --upgrade to refresh."`
  Also wire `--cursor` as a non-blocking INFO check in the default
  `walter-os doctor` output (no flag needed for basic presence check).
- Verify: `bin/walter-os doctor --cursor` returns:
  - MISSING when `~/.cursor/rules/walter-os.mdc` does not exist
  - PASS when it exists and is current
  - STALE when it exists but the hash is outdated (manually modify a line
    in the file to test this)
