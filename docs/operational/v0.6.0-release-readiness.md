## Tag Checklist

After the merge queue above is complete and this release-prep PR is merged:

1. Confirm `VERSION` is `0.6.0`.
2. Confirm README badge/status says `v0.6.0-alpha`.
3. Confirm `CHANGELOG.md` has `[0.6.0]`.
4. Run the full required CI suite on `main`.
5. Create and push the tag:

```bash
git checkout main
git pull --ff-only
git tag -a v0.6.0 -m "Walter-OS v0.6.0"
git push origin v0.6.0
```

The release workflow should then publish the release artifacts, checksums,
SBOM, cosign bundle, and SLSA provenance.
